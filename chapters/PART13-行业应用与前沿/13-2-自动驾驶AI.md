# 第 13-2 章：自动驾驶 AI

## 学习目标

- 了解自动驾驶的技术分级（SAE L0-L5）及其含义
- 掌握端到端自动驾驶的基本概念与技术路线
- 理解 BEV 感知、占用网络（Occupancy Network）等核心感知技术
- 了解 Tesla FSD 和 Waymo 的技术路线差异

---

## 1. 自动驾驶分级概述

国际汽车工程师学会（SAE）定义了自动驾驶级别：

| 等级 | 名称 | 人类驾驶参与度 | 系统职责 | 典型场景 |
|------|------|--------------|---------|---------|
| L0 | 无自动化 | 100% | 无 | 纯人工驾驶 |
| L1 | 驾驶辅助 | 监督 | 纵向控制（加减速）或横向（车道）之一 | ACC 自适应巡航 |
| L2 | 部分自动化 | 持续监督 | 纵向+横向，但需人类随时接管 | Tesla Autopilot、NOA |
| L3 | 条件自动化 | 特殊情况接管 | 在限定场景下完全自主，遇到未知场景请求人类 | Waymo One（特定区域） |
| L4 | 高度自动化 | 无需人类 | 在设计运行域内完全自主 | Robotaxi（无安全员） |
| L5 | 完全自动化 | 无需人类 | 任意场景、任意条件 | 尚未实现 |

**行业现状：**
- 绝大多数量产乘用车处于 L2 阶段（辅助驾驶）
- L4 主要在 Robotaxi、无人配送、特定封闭园区落地
- L5 是长期愿景，目前无法预期时间节点

## 2. 端到端自动驾驶（End-to-End Autonomous Driving）

### 2.1 什么是端到端？

传统自动驾驶系统采用**模块化流水线**：
```
感知 → 定位 → 预测 → 规划 → 控制
```

每个模块独立模型，模块之间通过人工定义的接口传递信息（如 3D 边界框、轨迹）。

**端到端自动驾驶**将感知到控制整合为一个可微分的神经网络：
```
传感器输入（图像/LiDAR/雷达）→ 神经网络 → 车辆控制指令（转向/油门/刹车）
```

代表工作：

| 年份 | 工作 | 机构 | 核心思想 |
|------|------|------|---------|
| 1988 | ALVINN | CMU | 最早的端到端自动驾驶，用神经网络从相机图像预测转向 |
| 2016 | NVIDIA DAVE-2 | NVIDIA | 用卷积网络从dashcam视频预测转向 |
| 2023 | UniAD | 上海人工智能实验室 | 全栈 transformer 端到端，提出"追踪一切以规划" |
| 2023 | Tesla FSD v12 | Tesla | 端到端规划，取消规则代码，输入图像直接输出控制 |
| 2024 | Wayve LINGO-2 | Wayve | 视觉-语言-动作模型，可解释的端到端驾驶 |

### 2.2 端到端的优势与挑战

**优势：**
- 信息损失少：避免模块间接口的信息瓶颈
- 全局优化：可从最终驾驶行为反向梯度优化所有模块
- 系统简洁：减少人工规则，降低维护成本

**挑战：**
- **可解释性差**：事故分析困难，无法精确定位问题根源
- **数据需求大**：需要海量真实驾驶数据
- **安全性验证难**：无法穷举所有长尾场景

## 3. BEV 感知与占用网络

### 3.1 BEV（Bird's Eye View）感知

BEV 感知是当前自动驾驶感知的主流范式。核心思想是将来自多个相机（或多种传感器）的特征统一转换到**俯视图坐标系**，再进行目标检测、车道线分割等任务。

**为什么需要 BEV？**

- 相机图像是透视投影（2D），存在远近遮挡问题
- BEV 坐标下可以直接做路径规划所需的 2D 地图表示
- 便于与 LiDAR、雷达等传感器融合

**技术路线：**

1. **基于深度估计的 IPM（Inverse Perspective Mapping）**：用几何方法做透视变换，受限于地面平面假设
2. **基于 Transformer 的 BEV 融合**：用 cross-attention 将多相机特征融合到 BEV  Query，典型工作：DETR3D（2021）、BEVFormer（2022）、Tesla BEV Net

### 3.2 占用网络（Occupancy Network）

传统目标检测只能识别训练时见过的类别（如车辆、行人、自行车）。**占用网络**将驾驶环境建模为 3D 体素网格，预测每个体素是否被占用。

**核心思想（Tesla 方案）：**
```
多相机图像 → 特征提取 → 3D 空间queries → 占用体积预测（每个体素：空/占用）
```

**优势：**
- 不受限于固定类别列表，可检测任意形状障碍物（如翻倒的卡车、散落物）
- 可预测运动物体的未来轨迹（通过时序占用变化）
- 弥补了长尾目标检测的数据不足问题

**后续发展：** Tesla Occupancy Network → Occupancy Flow（预测每个体素的运动矢量）→ 进一步演化为 **FSD v12 的 World Model** 基础

## 4. 主要玩家技术路线对比

### 4.1 Tesla FSD（Full Self-Driving）

Tesla 采用**纯视觉**方案，不使用 LiDAR 和高精地图：

| 要素 | Tesla 方案 |
|------|-----------|
| 感知传感器 | 8 个环绕摄像头（无 LiDAR、无毫米波雷达） |
| 感知框架 | BEV + Occupancy Network + 占用流 |
| 地图 | 众包建图（基于车队数据实时更新） |
| 规划 | 端到端（FSD v12 起用神经网络替代规则代码） |
| 技术路线 | 数据驱动、规模法则（scaling law），用海量行驶视频训练 |
| 核心芯片 | HW3.0 / HW4.0 自研 FSD 芯片 |

**核心特点：** 通过海量行驶数据（已收集数十亿英里）不断迭代，用影子模式收集 Corner Case。

### 4.2 Waymo

Waymo 采用**多传感器融合**方案，依赖高精地图：

| 要素 | Waymo 方案 |
|------|-----------|
| 感知传感器 | LiDAR + 摄像头 + 毫米波雷达 |
| 地图 | 高精地图（提前绘制，厘米级精度） |
| 定位 | 预制地图 + 实时点云配准 |
| 技术路线 | 传感器融合 + 规则引擎 + AI 感知 |
| 安全设计 | 多重冗余、远程操控员（ RCS ） |

**运营区域：** 凤凰城、旧金山、洛杉矶等，已实现无安全员商业运营（特定区域）。

### 4.3 对比总结

| 维度 | Tesla | Waymo |
|------|-------|-------|
| 传感器 | 纯视觉 | LiDAR + 摄像头 + 雷达 |
| 地图 | 众包实时地图 | 高精地图（离线制作） |
| 技术路线 | 数据驱动的规模法则 | 传感器融合 + 规则验证 |
| 商业化 | L2 辅助驾驶（乘用车） | L4 Robotaxi（出行服务） |
| 优势 | 成本低、数据多 | 精度高、安全冗余强 |
| 挑战 | L2 责任归属（驾驶员负责） | 成本高、扩张慢 |

## 5. World Model 与 VLM-AD：自动驾驶的新范式（2024-2025）

> **本节核心**：2024-2025 年自动驾驶 AI 出现**两条新主线**：
> 1. **World Model（世界模型）**：用生成式 AI 预测未来，做"想象训练"
> 2. **VLM-AD（视觉语言模型 + AD）**：用 GPT-4V 级别的多模态模型做驾驶决策

### 5.1 World Model for AD：让车"想象"未来

**核心思想**：训练一个**生成式视频模型**，能预测"如果我现在这么开，5 秒后会怎样"。

```mermaid
flowchart LR
    A[当前帧<br>+ 驾驶动作] --> B[World Model<br>视频生成]
    B --> C[预测未来<br>5-30 秒]
    C --> D{安全吗？}
    D -->|是| E[执行动作]
    D -->|否| F[重新规划]
    style B fill:#FFE4B5
    style C fill:#90EE90
```

**代表工作**：

| 模型 | 机构 | 时间 | 核心思想 |
|------|------|------|----------|
| **GAIA-1** | Wayve | 2023 | 视频扩散模型预测驾驶未来 |
| **DriveDreamer** | 中山大学/上海 AI Lab | 2023 | 驾驶视频生成 + 决策 |
| **Copilot4D** | Waabi | 2024 | 4D 世界模型（3D + 时间）|
| **Vista** | MIT | 2024 | 高保真视频预测 |
| **GAIA-2** | Wayve | 2024 | 加入动作条件 / 多视角 |
| **GenAD** | 上海 AI Lab | 2024 | 通用自动驾驶生成式世界模型 |
| **MagicDrive** | 中科院 | 2024 | 高分辨率街景生成 |
| **DrivingGPT** | 复旦 | 2024 | 驾驶决策 + 解释 |

**World Model 的 3 大优势**：

1. **想象训练（Imagination Training）**：在"想象空间"中训练策略，无需真实危险动作
2. **长尾场景生成**：罕见危险场景（小孩突然冲出）可以生成
3. **可解释性**：可以"展示"AI 看到的世界

**局限**：
- 生成的视频可能不真实（幻觉）
- 训练算力需求巨大（数千 GPU-days）
- 评估困难（生成的视频"看起来对"≠"驾驶决策对"）

### 5.2 VLM-AD：让 GPT-4V 开车

**核心思想**：用大型多模态模型（VLM）做驾驶决策。

**代表工作**：

| 模型 | 机构 | 时间 | 输入 | 输出 |
|------|------|------|------|------|
| **DriveGPT4** | 中科院 | 2023 | 多视角视频 + 文本问题 | 驾驶动作 + 解释 |
| **LMDrive** | 厦门大学 | 2023 | 多模态 | 控制信号 + 语言解释 |
| **DriveVLM** | 上汽/上海 AI Lab | 2024 | 视频 | 决策树 + 解释 |
| **RAG-Driver** | 清华 | 2024 | 视频 + 检索增强 | 决策 + 解释 |
| **LMDrive++** | CMU | 2024 | 视频 + 语言 | 6D 控制 + 解释 |
| **Hugging Face LeRobot** | HF | 2024 | 多模态 VLA | 机器人控制 |

**典型 Prompt**（DriveVLM）：

```
你是一位自动驾驶 AI。当前场景：
[图像：十字路口，红灯，倒计时 5 秒]
[前车状态：已停]

请决策：
1. 立即动作（油门/刹车/转向）
2. 动作理由（用一句话解释）
3. 风险评估

输出格式：
- 动作：刹车（减速 0.3 m/s²）
- 理由：红灯即将转绿，但仍有 5 秒，前车已停，安全优先
- 风险：低
```

**VLM-AD 的 3 大优势**：
1. **可解释**：能用人话解释"为什么这么开"
2. **泛化强**：训练数据里没见过的场景也能"理解"
3. **人机交互**：乘客可以直接对话

**局限**：
- 推理慢（GPT-4V 几秒才能决策一次）
- 不能精确控制（无法输出连续刹车力）
- 安全不可证明（VLM 仍有幻觉）

### 5.3 端到端 + World Model + VLM 的"三体"融合

**当前最前沿的范式**（Wayve、Waabi、Tesla FSD v12/v13）：

```mermaid
flowchart TD
    A[多摄像头 + LiDAR] --> B[感知<br>Perception]
    B --> C[World Model<br>预测未来]
    C --> D[VLM 推理<br>高层决策]
    D --> E[规划轨迹<br>Trajectory]
    E --> F[底层控制<br>Control]
    
    style B fill:#FFE4B5
    style C fill:#FFA500
    style D fill:#90EE90
    style F fill:#87CEEB
```

**代表公司**：
- **Wayve**（英国）：LINGO-2 / GAIA-2 / PRISM-1（VLM + World Model）
- **Tesla**：FSD v13（端到端 + 占据网络）
- **Waabi**（加拿大）：Copilot4D（World Model + 自动驾驶）
- **Waymo**（Alphabet）：EMMA（端到端多模态 AD）
- **百度**：ADFM（VLM 端到端）
- **华为**：盘古汽车大模型

### 5.4 2024-2025 三大趋势

1. **VLM 端到端成为主流**：Wayve LINGO、DriveVLM、EMMA 等用 VLM 替换传统模块
2. **World Model 加速落地**：Wayve GAIA-2、Tesla FSD v13 用想象训练
3. **占据网络（Occupancy Network）替代 3D 检测**：Tesla FSD v12/v13、华为 ADS 3.0

### 5.5 自动驾驶的未来 5 大挑战

| 挑战 | 现状 | 趋势 |
|------|------|------|
| **长尾场景** | 千万公里才有 1 次 | World Model 生成 + 数据闭环 |
| **极端天气** | 雨雪雾仍难处理 | 多模态融合 + 物理先验 |
| **VLM 幻觉** | 关键决策可能错 | 安全约束 + 规则兜底 |
| **法规与责任** | L3 才刚立法 | L4 仍需"安全员" |
| **数据效率** | 100 亿公里数据 | 数据闭环 + 合成数据 |

## 本章小结
自动驾驶 AI 的技术演进呈现两条主要路径：

1. **渐进式（Tesla 路线）**：从 L2 辅助驾驶逐步逼近 L4，靠数据规模和端到端模型迭代
2. **跨越式（Waymo 路线）**：直接瞄准 L4 落地，用高精地图和高安全性冗余设计

**BEV 感知 + 占用网络**是当前感知模块的核心范式。**端到端神经网络**正在逐步替代传统模块化流水线，但安全性验证仍是大规模落地的核心挑战。
