## 1. 词向量表示的演进

### 1.1 传统表示：One-Hot 编码

早期 NLP 使用 One-Hot 编码表示词：

```
词汇表: [the, cat, sat, on, mat]

the → [1, 0, 0, 0, 0]
cat → [0, 1, 0, 0, 0]
mat → [0, 0, 0, 0, 1]
```

**问题**：
- 维度灾难（词表越大，向量越长）
- 语义鸿沟（"cat" 和 "dog" 的表示完全独立）
- 无法表达词语之间的关系

### 1.2 分布式表示：词向量

分布式假说："**一个词的意义由它的上下文决定**"

```
┌─────────────────────────────────────────────────────────────┐
│              词向量表示的优势                               │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   One-Hot:               词向量:                            │
│   the = [1,0,0...]       the ≈ [0.2, 0.8, -0.3]          │
│   cat = [0,1,0...]       cat ≈ [0.1, 0.9, -0.1]          │
│   dog = [0,0,1...]       dog ≈ [0.1, 0.85, -0.15]        │
│                                                             │
│   cat 和 dog 的向量相似度高！                              │
│   这就是"语义相似"的向量表示                              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 2. Word2Vec：里程碑式工作

### 2.1 概述

Word2Vec 由 Google 的 Tomas Mikolov 团队于 2013 年提出，是第一个高效训练词向量的工具。

**核心思想**：通过神经网络学习词的低维向量表示，使得语义相似的词在向量空间中距离相近。

### 2.2 两种模型架构

```
┌─────────────────────────────────────────────────────────────┐
│                    CBOW vs Skip-Gram                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   CBOW (Continuous Bag of Words):                           │
│   ┌─────────┐                                              │
│   │ 上下文   │ → [the, cat, on, mat]                      │
│   │ 窗口     │                                              │
│   └────┬────┘                                              │
│        │                                                    │
│        ▼                                                    │
│   ┌─────────┐     ┌─────────┐                             │
│   │  神经网络 │ ──→ │  预测    │ → "sat"                  │
│   │  (简单)  │     │          │                            │
│   └─────────┘     └─────────┘                             │
│   用上下文预测中心词                                          │
│                                                             │
│   ─────────────────────────────────────────────────────     │
│                                                             │
│   Skip-Gram:                                               │
│   ┌─────────┐                                              │
│   │ 中心词   │ → "sat"                                     │
│   │         │                                              │
│   └────┬────┘                                              │
│        │                                                    │
│        ▼                                                    │
│   ┌─────────┐     ┌─────────┐                             │
│   │  神经网络 │ ──→ │  预测    │ → [the, cat, on, mat]   │
│   │  (简单)  │     │  多个词  │                            │
│   └─────────┘     └─────────┘                             │
│   用中心词预测上下文                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 CBOW 模型详解

**输入**：上下文词的 One-Hot 向量

**结构**：浅层双层神经网络

```
CBOW 网络结构：

Input (One-Hot, V 维)          Hidden (N 维)              Output (V 维)
┌──────────────────┐          ┌────────────┐          ┌──────────────────┐
│ w(t-2) ──→  ──→ │          │            │          │                  │
│ w(t-1) ──→  ──→ │ ──→ * ──→│   Linear   │───→*──→│   Softmax       │
│ w(t+1) ──→  ──→ │  叠加平均   │   (N维)    │          │                  │
│ w(t+2) ──→  ──→ │          │            │          │                  │
└──────────────────┘          └────────────┘          └──────────────────┘
      V 维                        N 维                  V 维 (词表大小)
```

**数学表达**：

输入层到隐藏层：
$$h = \frac{1}{C} W^T (x_1 + x_2 + ... + x_C)$$

隐藏层到输出层：
$$y = softmax(W'^T h)$$

### 2.4 Skip-Gram 模型详解

Skip-Gram 是 Skip-Gram 的镜像，用中心词预测上下文：

```
Skip-Gram 网络结构：

Input (One-Hot, V 维)          Hidden (N 维)              Output (多个 V 维)
┌──────────────────┐          ┌────────────┐          ┌──────────────────┐
│   w(t)           │ ──→ ──→ │   Linear   │───→*──→│ w(t-2)           │
│   (中心词)       │  直接传递  │   (N维)    │  C个输出 │ w(t-1)           │
│                  │          │            │          │ w(t+1)           │
└──────────────────┘          └────────────┘          │ w(t+2)           │
                                                       └──────────────────┘
```

**目标函数**（Skip-Gram）：
$$\mathcal{L} = \sum_{t=1}^{T} \sum_{-c \leq j \leq c, j \neq 0} \log P(w_{t+j} | w_t)$$

其中 $c$ 是上下文窗口大小。

### 2.5 关键技术：负采样

**问题**：标准 Softmax 需要计算整个词表的归一化项，计算量巨大。

**解决方案**：负采样（Negative Sampling）

```
┌─────────────────────────────────────────────────────────────┐
│                    负采样示意                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   正样本（来自语料）：                                       │
│   中心词 "cat" → 上下文 "sat"  ✓                          │
│                                                             │
│   负样本（随机采样）：                                       │
│   中心词 "cat" → 随机词 "apple"  ✗                        │
│   中心词 "cat" → 随机词 "chair"  ✗                        │
│   中心词 "cat" → 随机词 "window"  ✗                        │
│                                                             │
│   训练目标：最大化正样本概率，最小化负样本概率               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**负采样目标函数**：
$$\log \sigma(v'_{w_O}^T v_{w_I}) + \sum_{i=1}^{k} \mathbb{E}_{w_i \sim P_n(w)}[\log \sigma(-v'_{w_i}^T v_{w_I})]$$

## 3. 对比学习：自监督预训练

### 3.1 什么是自监督学习？

自监督学习是一种**无需人工标注数据**的学习范式，通过设计辅助任务（Pretext Task）从数据本身挖掘监督信号。

```
┌─────────────────────────────────────────────────────────────┐
│                 自监督学习 vs 监督学习                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   监督学习:                                                 │
│   数据 → 模型 → 预测 → 与真实标签对比 → 反向传播              │
│           (需要人工标注)                                     │
│                                                             │
│   自监督学习:                                               │
│   数据 → 设计Pretext任务 → 自动生成"伪标签" → 反向传播        │
│           (无需人工标注)                                     │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 对比学习核心思想

**核心目标**：让相似样本的表示更接近，不相似样本的表示更远离。

```
┌─────────────────────────────────────────────────────────────┐
│                 对比学习示意                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   特征空间:                                                 │
│                                                             │
│        ◇ 猫1 (正)          ◇ 猫2 (正)                       │
│           ↖ ↗                 ↖ ↗                        │
│            ╲ ╱                   ╲ ╱                         │
│             ● 猫 (锚点)           ● 狗 (锚点)               │
│            ╱ ╲                   ╱ ╲                         │
│           ↙ ↘                 ↙ ↘                          │
│        ○ 车1 (负)           ○ 车2 (负)                     │
│                                                             │
│   目标: 最小化同类距离，最大化异类距离                        │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.3 InfoNCE 损失函数

Contrastive Learning 常用的损失函数：

$$L = -\log \frac{\exp(sim(z_i, z_j) / \tau)}{\sum_{k=1}^{2N} \mathbf{1}_{[k \neq i]} \exp(sim(z_i, z_k) / \tau)}$$

其中：
- $z_i, z_j$ 是正样本对
- $\tau$ 是温度系数
- $N$ 是 batch size

### 3.4 MoCo：动量对比

MoCo（Momentum Contrast）由 Kaiming He 等人于 CVPR 2020 提出，是对比学习的重要里程碑。

**核心创新**：
1. **动态字典**（Dynamic Dictionary）：将过往样本的特征存储在队列中作为负样本
2. **动量更新**：避免 encoder 参数变化过快导致特征不一致

```
┌─────────────────────────────────────────────────────────────┐
│                      MoCo 架构                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   查询编码器 q = f_q(x_query)                               │
│              │                                              │
│              │         ┌──────────────┐                     │
│              └───────→│    对比损失   │ ←── 键编码器 k = f_k(x_key)│
│                         └──────────────┘                     │
│                              ▲                               │
│                              │                               │
│                      ┌────────┴────────┐                     │
│                      │   动量更新     │                     │
│                      │   m = 0.999   │                     │
│                      └────────┬────────┘                     │
│                               │                             │
│   键队列 (负样本缓存):        │                             │
│   [k_1, k_2, ..., k_N]      │                             │
│                               │                             │
│   新键入队，旧键出队 ◄────────┘                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**伪代码**：
```python
# 查询编码器
q = encoder_q(x_query)  # 在线更新
# 键编码器 (动量更新)
k = encoder_k(x_key)    # 缓慢更新

# 对比损失
logits = torch.mm(q, queue.clone().detach())  # 正样本在位置 0
loss = cross_entropy(logits, torch.zeros(logits.shape[0]))  # 正确分类正样本

# 动量更新键编码器
encoder_k.param = m * encoder_k.param + (1-m) * encoder_q.param

# 队列更新
queue = torch.cat([queue[1:], k.detach()], dim=0)
```

### 3.5 SimCLR：简单框架

SimCLR（A Simple Framework for Contrastive Learning of Visual Representations）由 T. Chen 等人于 2020 年提出。

**核心思想**：
1. 同一图像的不同数据增强视为正样本
2. 同一 batch 内其他图像视为负样本
3. 使用 Projection Head 增强表示

```
┌─────────────────────────────────────────────────────────────┐
│                    SimCLR 流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   图像 x ──→ 数据增强 ──→ x_i ──→ 编码器 f(·) ──→ h_i    │
│                        │                                    │
│                        └──→ x_j ──→ 编码器 f(·) ──→ h_j    │
│                                    │                        │
│                                    ▼                        │
│                              投影头 g(·)                    │
│                                    │                        │
│                                    ▼                        │
│                              z_i, z_j (用于对比)             │
│                                                             │
│   损失: L = -log(exp(sim(z_i,z_j)/τ) /                     │
│              Σ_k exp(sim(z_i,z_k)/τ))                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**SimCLR 的关键发现**：
- **数据增强非常关键**：多种增强组合优于单一增强
- **Projection Head 有用**：非线性投影比线性投影效果好
- **Batch Size 越大越好**：更多负样本
- **训练时间越长越好**：对比学习需要更多 epoch

### 3.6 对比学习在 NLP 中的应用

| 方法 | 领域 | 核心思想 |
|------|------|----------|
| **Word2Vec** | NLP | 用上下文预测中心词（CBOW）或相反（Skip-Gram） |
| **CPC** | Audio/NLP | 通过预测未来信息学习表示 |
| **MoCo** | Vision | 动量更新的动态负样本队列 |
| **SimCLR** | Vision | 同一图像的不同增强视为正样本 |
| **CLIP** | Multimodal | 图文对比学习 |

## 本章小结

1. **词向量**将词映射到低维连续向量空间，使得语义相似的词在空间中距离相近
2. **Word2Vec** 提出 CBOW 和 Skip-Gram 两种高效训练词向量的方法
3. **负采样**解决了 Softmax 在大词表上的计算效率问题
4. **对比学习**通过让正样本靠近、负样本远离来学习表示
5. **MoCo** 通过动量更新和动态负样本队列提升了对比学习效率
6. **SimCLR** 证明了数据增强、projection head 和大 batch 对对比学习的重要性
