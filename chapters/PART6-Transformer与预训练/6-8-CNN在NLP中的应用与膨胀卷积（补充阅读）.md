## 1. CNN 为什么能用于 NLP？

### 1.1 文本的矩阵表示

CNN 最初用于计算机视觉（图像像素矩阵），但同样适用于 NLP 任务。关键是将文本表示为矩阵：

```
┌─────────────────────────────────────────────────────────────┐
│              文本的矩阵表示                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   句子："The cat sat on the mat"                            │
│                                                             │
│   词嵌入维度 d = 5                                         │
│                                                             │
│   词向量矩阵 X ∈ R^{n×d}：                                │
│                                                             │
│         the   0.2  0.1  -0.3  0.5  0.2                   │
│         cat   0.8  0.3   0.1  -0.2  0.4                  │
│         sat   0.1  0.9  -0.4  0.3  0.1                   │
│         on    -0.2 0.4   0.5  0.1  -0.3                 │
│         the   0.2  0.1  -0.3  0.5  0.2                   │
│         mat   0.3  0.2   0.1  0.4  -0.1                  │
│                                                             │
│   n = 6 个词，每个词是 d = 5 维向量                         │
│   矩阵形状：6 × 5                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 一维卷积与二维卷积的区别

```
┌─────────────────────────────────────────────────────────────┐
│              一维卷积 vs 二维卷积                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   二维卷积（图像）：                                         │
│   ┌───────────────────┐                                    │
│   │ ░░░░░░░░░░░░░░░ │  宽度 × 高度 × 通道              │
│   │ ░░░░░░░░░░░░░░░ │  像素间有空间关系               │
│   │ ░░░░░░░░░░░░░░░ │                                  │
│   └───────────────────┘                                    │
│                                                             │
│   一维卷积（文本）：                                         │
│   ┌───────────────────┐                                    │
│   │ the cat sat on mat│  序列长度 n × 词向量维度 d       │
│   │ ▓▓▓▓▓▓▓▓▓▓▓▓▓▓ │  卷积核宽度 = d（完整词向量）   │
│   └───────────────────┘                                    │
│            ↓ 滑动方向                                        │
│                                                             │
│   ┌─────────────────────────────────────────────────────┐  │
│   │  kernel_size = 3 (覆盖 3 个词)                     │  │
│   │  每次处理 3 × d 的窗口                              │  │
│   └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

```
├─────────────────────────────────────────────────────────────┤

│                                                             │
│   卷积层：                                                  │
│   ┌─────────┐                                              │
│   │ conv 3 │ → 3-gram 特征                                │
│   ├─────────┤                                              │
│   │ conv 4 │ → 4-gram 特征                                │
│   ├─────────┤                                              │
│   │ conv 5 │ → 5-gram 特征                                │

│   池化层：                                                  │
│   ┌─────────┐                                              │
│   │ 1-max   │ → 每个特征取最大值                           │

```

## 2. 膨胀卷积（Dilated Convolution）

### 2.1 膨胀卷积的核心思想

膨胀卷积通过在卷积核内部引入"空洞"来扩大感受野，同时保持参数量不变：

```
┌─────────────────────────────────────────────────────────────┐
│              标准卷积 vs 膨胀卷积                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   标准卷积（dilation rate = 1）：                            │
│   ┌───────────────────────────┐                            │
│   │  ●  ●  ●  ●  ●  ●  ●  │                            │
│   │  ←── kernel size = 3 ──→  │                          │
│   └───────────────────────────┘                            │
│                                                             │
│   膨胀卷积（dilation rate = 2）：                           │
│   ┌───────────────────────────┐                            │
│   │  ●  ○  ●  ○  ●  ○  ●  │                            │
│   │  ←─┼── kernel size = 3 ──┼──→  │                     │
│   │       ↑                    ↑                            │
│   │    空洞（dilation）      空洞                          │
│   └───────────────────────────┘                            │
│                                                             │
│   ● = 参与计算     ○ = 不参与计算（空洞）                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 感受野计算

```
┌─────────────────────────────────────────────────────────────┐
│              感受野计算公式                                    │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   等效卷积核大小：                                          │
│                                                             │
│   k' = k + (k - 1) × (d - 1)                            │
│                                                             │
│   其中：                                                    │
│   • k = 原始卷积核大小                                     │
│   • d = dilation rate（膨胀率）                            │
│                                                             │
│   示例：                                                    │
│   • k = 3, d = 1 → k' = 3 + 2×0 = 3（标准卷积）        │
│   • k = 3, d = 2 → k' = 3 + 2×1 = 5                   │
│   • k = 3, d = 4 → k' = 3 + 2×3 = 9                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.3 多层膨胀卷积的感受野增长

```
┌─────────────────────────────────────────────────────────────┐
│              多层膨胀卷积的感受野                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Layer 1: dilation=1, kernel=3                            │
│   ┌───────────────┐                                        │
│   │ ● ● ●        │  感受野 = 3                           │
│   └───────────────┘                                        │
│                                                             │
│   Layer 2: dilation=2, kernel=3                            │
│   ┌───────────────────────────────┐                        │
│   │ ●  ○  ●  ○  ●                │  感受野 = 7           │
│   └───────────────────────────────┘                        │
│                                                             │
│   Layer 3: dilation=4, kernel=3                            │
│   ┌───────────────────────────────────────────────────┐   │
│   │ ●  ○  ○  ○  ●  ○  ○  ○  ●                        │  感受野 = 15
│   └───────────────────────────────────────────────────┘   │
│                                                             │
│   感受野增长：3 → 7 → 15 → 31 → ...                       │
│   公式：感受野 = 1 + n×(k-1)×d^n - 1 / (d-1)            │
│                                                             │
│   ✓ 指数级增长，仅需 O(log N) 层即可覆盖整个序列            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.4 膨胀卷积的栅格效应与解决方案

```
┌─────────────────────────────────────────────────────────────┐
│              栅格效应（Gridding Effect）                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   问题：连续的 dilation=2 膨胀卷积会导致感受野不连续          │
│                                                             │
│   Layer 1 (d=1): ● ● ●                                    │
│   Layer 2 (d=2): ● ○ ● ○ ●                               │
│   Layer 3 (d=4): ● ○ ○ ○ ● ○ ○ ○ ●                      │
│                                                             │
│   ↑ 某些位置（如 index 2, 6）被跳过，信息丢失              │
│                                                             │
│   解决方案：使用锯齿状膨胀率（HDC 原则）                    │
│                                                             │
│   推荐膨胀率序列：                                          │
│   • [1, 2, 4, 8, 16, ...]  指数增长                     │
│   • [1, 2, 3, 4, 5, ...]   线性增长                     │
│                                                             │
│   锯齿状序列：                                             │
│   • [1, 2, 4, 1, 2, 4, 1, 2, 4, ...]                  │
│   Layer 1 (d=1): ● ● ●                                    │
│   Layer 2 (d=2): ● ○ ● ○ ●                               │
│   Layer 3 (d=4): ● ○ ○ ○ ●                               │
│   Layer 4 (d=1): ● ● ●                                    │
│   ...                                                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 3. GLU：门控线性单元

### 3.1 GLU 的核心思想

GLU（Gated Linear Unit）由 Dauphin 等人（2017）提出，将 LSTM 的门机制引入 CNN：

```
┌─────────────────────────────────────────────────────────────�
│              GLU vs 标准卷积                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   标准卷积：                                                │
│   y = W * x + b                                            │
│   y = activation(y)                                        │
│                                                             │
│   GLU：                                                   │
│   y = (W1 * x + b1) ⊗ σ(W2 * x + b2)                   │
│                                                             │
│   其中：                                                    │
│   • W1 * x + b1：特征提取                                 │
│   • σ(W2 * x + b2)：门控信号（0-1 之间）                 │
│   • ⊗：逐元素相乘                                          │
│                                                             │
│   直观理解：                                                │
│   • 特征提取部分像标准卷积                                  │
│   • 门控部分决定保留多少信息                                 │
│   • 类似 LSTM 的遗忘门/输入门                               │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 3.2 GLU 在 NLP CNN 中的作用

```
┌─────────────────────────────────────────────────────────────┐
│              GLU 在 CNN 中的应用                             │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Convolutional Sequence to Sequence Learning (Conv Seq2Seq) │
│                                                             │
│   输入：词嵌入矩阵                                          │
│        ↓                                                    │
│   并行卷积层（GLU 激活）                                   │
│   ┌─────────────────────────────────────────────────────┐ │
│   │  for each position:                                  │ │
│   │    filter = W1 * window + b1                        │ │
│   │    gate = sigmoid(W2 * window + b2)                │ │
│   │    output = filter ⊗ gate                          │ │
│   └─────────────────────────────────────────────────────┘ │
│        ↓                                                    │
│   残差连接                                                │
│        ↓                                                    │
│   堆叠多层以捕获长距离依赖                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 4. CNN 在 NLP 中的典型应用

### 4.1 文本分类

TextCNN 是最经典的 CNN 文本分类模型：

```python
class TextCNN(nn.Module):
    def __init__(self, vocab_size, embed_dim, num_classes, kernel_sizes=[3, 4, 5]):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embed_dim)
        # 并行多尺寸卷积
        self.convs = nn.ModuleList([
            nn.Conv1d(embed_dim, embed_dim, k) for k in kernel_sizes
        ])
        self.dropout = nn.Dropout(0.5)
        self.fc = nn.Linear(embed_dim * len(kernel_sizes), num_classes)

    def forward(self, x):
        # x: (batch, seq_len)
        x = self.embedding(x)  # (batch, seq_len, embed_dim)
        x = x.permute(0, 2, 1)  # (batch, embed_dim, seq_len)

        # 多尺寸卷积 + 1-max pooling
        conv_outs = []
        for conv in self.convs:
            c = torch.relu(conv(x))  # (batch, embed_dim, seq_len-k+1)
            c = torch.max(c, dim=2)[0]  # (batch, embed_dim)
            conv_outs.append(c)

        # 拼接 + 全连接
        x = torch.cat(conv_outs, dim=1)  # (batch, embed_dim * 3)
        x = self.dropout(x)
        return self.fc(x)
```

### 4.2 序列到序列（Seq2Seq）

```
┌─────────────────────────────────────────────────────────────┐
│              Conv Seq2Seq 结构                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   编码器：                                                  │
│   输入 Embedding                                             │
│        ↓                                                    │
│   [Conv + GLU] × N 层                                      │
│        ↓                                                    │
│   输出隐藏状态                                               │
│                                                             │
│   解码器：                                                  │
│   目标 Embedding                                            │
│        ↓                                                    │
│   [Conv + GLU] × N 层                                      │

│   输出投影 + Softmax                                         │
│                                                             │
│   特点：                                                    │
│   • 完全并行（无 RNN 的时序依赖）                           │
│   • 位置编码必须显式加入                                    │
│   • GLU 门控帮助信息流动                                    │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 6. CNN 与 Transformer 的融合

现代模型发展趋势是**融合 CNN 和 Transformer 的优点**：

### 6.1 ConvNeXt：CNN 学习 Transformer

ConvNeXt（2022）将 Transformer 的设计理念引入 CNN：

```
┌─────────────────────────────────────────────────────────────┐
│              ConvNeXt 的 Transformer 设计借鉴                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   Transformer 特性          →  ConvNeXt 实现               │
│   ─────────────────────────────────────────────────────     │
│   大卷积核（如 7×7）       →  7×7 深度可分离卷积          │
│   LayerNorm                 →  BatchNorm                  │
│   GELU 激活                →  GELU                      │
│   多头注意力               →  逐点卷积 + 通道注意力       │
│   FFN（4×隐藏层）          →  FFN（4×隐藏层）            │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 6.2 CoAtNet：CNN + Transformer 混合

```
┌─────────────────────────────────────────────────────────────┐
│              CoAtNet 结构                                      │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   阶段 1：Conv Stage（局部特征）                            │
│   输入 → [MBConv + SE] × N → 局部特征图                    │
│                                                             │
│   阶段 2：Transformer Stage（全局依赖）                     │
│   局部特征 → 展平 → [Relative Attention + FFN] × N       │
│                                                             │
│   关键创新：                                                │
│   • 用相对位置编码替代绝对位置编码                          │
│   • 在浅层用 CNN 捕获局部模式                              │
│   • 在深成用 Transformer 捕获全局依赖                      │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 本章小结

1. **一维 CNN** 可以有效处理文本序列，卷积核覆盖连续的词窗口
2. **TextCNN** 通过多尺寸卷积核（3/4/5-gram）捕获不同范围的局部特征
3. **膨胀卷积**通过引入空洞，可以在不增加参数的情况下指数级扩大感受野
4. **GLU** 门控机制帮助 CNN 学习更复杂的依赖关系
5. **CNN 的优势**在于并行计算效率高，适合局部特征提取
6. **CNN 的劣势**在于长距离依赖需要深层堆叠
7. **现代趋势**是融合 CNN 和 Transformer 的优点（ConvNeXt、CoAtNet）
